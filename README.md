# キャッシュ・フロー電卓（EE電卓）

設備投資案の経済性を評価するための、スマートフォン向けの計算ツールです。
初期投資と各期の報収を入力すると、正味現価（NPV）・正味年価・正味終価、投資利益率（IRR）、割引回収期間などをその場で計算します。
経済性分析（Engineering Economy）の授業・研修での学習用に作成しました。

**公開ページ：** https://【ユーザー名】.github.io/cf-calc/

インストールや登録は不要です。スマートフォンやパソコンのブラウザで上のURLを開くだけで使えます。

---

## できること

- 1案から最大3案までの投資案を同時に評価・比較
- 各案について次の値を計算
  - 正味現価・正味年価・正味終価
  - 投資利益率（IRR）：解が複数ある場合はすべて表示
  - 割引回収期間（PBP）
  - 許容投資額・必要回収額（年あたり）
- 複数案の比較のための「差の案」（追加投資案）
  - 追加投資額、追加報収、追加投資利益率、追加回収期間、差の正味現価・正味年価
- キャッシュ・フロー図（案ごと）
- 回収残高（プロジェクト・バランス）の推移グラフと表（全案を重ねて表示）

## 使い方

1. **資本の利率 i** を％で入力します（例：10% なら `10`）。
2. 案ごとに入力方式を選びます。
   - **等報収**：初期投資 C、毎期末の報収 R、計画期間 n を入力します。
   - **一般型**：0年目、1年目、2年目……の各期の金額を入力します。「＋1年（前年と同額）」で期を追加できます。
3. 数値を入れると、その場で計算結果が表示されます（計算ボタンはありません）。
4. 「＋ 案を追加して比較する」で案を増やすと、差の案と回収残高のグラフに反映されます。
5. 「例を読み込む」のボタンで、例題の数値を読み込めます。

### スマートフォンのホーム画面に追加する

- **Android（Chrome）**：右上の「︙」→「ホーム画面に追加」
- **iPhone（Safari）**：共有ボタン →「ホーム画面に追加」

アプリのように起動できるようになります。

### 入力のルール

- **金額は符号付きで入力します。** 支出（投資額など）はマイナス、収入（報収・節減額など）はプラスです。
  - 例：初期投資 1,000万円 → `-1000`
- マイナス記号が打てないキーボードでは、入力欄の左端の「**±**」ボタンで符号を切り替えられます。
- 全角の数字・記号（「１０００」「－」など）も入力できます。
- 金額の単位は自由です（万円・億円など）。ただし、結果は**小数点以下1桁**で表示されるため、億円単位で入力すると丸めの影響が大きくなります。万円単位での入力をおすすめします。
- 入力した値は、使っている端末のブラウザ内にだけ保存されます。外部に送信されることはありません。

## 計算の定義

記号：各期のキャッシュ・フローを CF₀, CF₁, …, CFₙ、資本の利率を i とします。すべて**期末払い**として計算します。

| 指標 | 計算方法 |
|---|---|
| 正味現価 | NPV = Σ CFₜ / (1+i)ᵗ |
| 正味年価 | NPV × [P→M]ⁱₙ（資本回収係数） |
| 正味終価 | NPV × (1+i)ⁿ |
| 許容投資額 | −（1期以降の報収の現価）。初期投資と同じ符号（マイナス）で表示 |
| 必要回収額 | −CF₀ × [P→M]ⁱₙ |
| 投資利益率（IRR） | NPV(r) = 0 となる r（下記） |
| 割引回収期間（PBP） | 回収残高が 0 になる時点（下記） |

### 投資利益率（IRR）の求め方

r を −99% から +1,101% まで 0.1% 刻みで調べ、NPV の符号が変わる区間を二分法で絞り込んで求めます。
解が複数ある場合（キャッシュ・フローの符号が途中で複数回変わる場合）は、すべての解を「10.00 % / 40.00 %」のように表示します。
解がない場合は「なし」と表示します。

### 割引回収期間（PBP）の求め方

- **1期以降の報収がすべて同額の場合**：
  N = −ln(1 − i·C/R) / ln(1+i)（Excel の NPER 関数と同じ式）
  i = 0 のときは N = C/R（単純回収期間）
- **報収が不均等な場合**：回収残高 Bₜ（下記）が負から正に転じる期の間を直線で補間します。
  N = (t−1) + (−Bₜ₋₁) / (Bₜ − Bₜ₋₁)
  回収残高がいったん正になった後に再び負になる場合は、**最後に正に転じた時点**を回収期間とします。
- 回収できない場合は「回収不能」と表示します。
- 回収期間は小数で表示します。整数年で答える場合は、小数を切り上げた年（その期末に回収が確定する年）と読み替えてください。

### 回収残高（プロジェクト・バランス）

B₀ = CF₀、Bₜ = Bₜ₋₁ × (1+i) + CFₜ

### 差の案（追加投資案）

各案を初期投資額の小さい順（|CF₀| の小さい順）に並べ、隣り合う案どうしの差（大きい案 − 小さい案）のキャッシュ・フローを評価します。
期間の異なる案どうしでは、短い案の期間を過ぎた年の金額を 0 として差をとります。

## 現在の制約

| 内容 | 対応方法 |
|---|---|
| 期首払いには対応していません | 期末払いに換算して入力してください |
| 計画期間 n は整数のみ | ― |
| n = ∞（永続）の入力欄はありません | n = 1000 などの十分大きな値で代用できます |
| 比較できる案は最大3案、差の案は隣り合う案どうしのみ | ― |

## 検算用の例題

次の値と一致することを確認しています（i：資本の利率）。改良後の動作確認にも使えます。

| 例題 | 入力 | 結果 |
|---|---|---|
| 等報収 | C=−3000, R=850, n=10, i=10% | 正味現価 2,222.9、正味年価 361.8、正味終価 5,765.6 |
| 一般型 | −1000, 500, 400, 300, 300, 250, i=10% | 正味現価 370.7 |
| IRR | C=−4500, R=800, n=10 | 12.11% |
| 回収期間 | C=−1000, R=250, n=10, i=10% | 5.36年 |
| 回収残高 | C=−2000, R=1200, n=5, i=10% | −2000, −1000, 100, 1310, 2641, 4105.1（回収期間 1.91年） |
| 排反案 | 案A：C=−1500, R=350／案B：C=−3000, R=650（n=8, i=10%） | 正味現価 A 367.2、B 467.7／差の案 B−A：差の正味現価 100.5、追加投資利益率 11.81%、追加回収期間 7.27年 |
| コスト型 | C=−800, R=−300, n=3, i=12% | 正味年価 −633.1 |
| 複数解 | −1000, 2500, −1540 | IRR 10.00% / 40.00% |

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 電卓本体。HTML・CSS・JavaScript をこの1ファイルにまとめています |
| `manifest.webmanifest` | ホーム画面に追加したときのアプリ名・アイコンの設定 |
| `icon-192.png`, `icon-512.png` | アイコン画像 |

外部のライブラリは使っていません（フォントのみ Google Fonts から読み込み）。

### 改良するときの手がかり

`index.html` の後半の `<script>` 内に、計算と表示の処理があります。主な関数は次のとおりです。

| 関数・定数 | 役割 |
|---|---|
| `num` | 入力文字列を数値に変換（全角の正規化を含む） |
| `npvAt`, `PM` | 正味現価、資本回収係数 |
| `irrs` | 投資利益率（すべての解）の探索 |
| `pbp` | 割引回収期間の計算 |
| `cfOf` | 入力からキャッシュ・フローの配列を作成 |
| `evaluate` | 1案（または差の案）の全指標を計算 |
| `balances` | 回収残高の計算 |
| `cfDiagram` | キャッシュ・フロー図の描画（SVG） |
| `drawBal` | 回収残高グラフと表の描画 |
| `renderPlans`, `compute` | 入力欄の生成と、計算・表示の更新 |
| `EX` | 「例を読み込む」の例題データ |

入力値はブラウザの localStorage に `cfcalc-v1` というキーで保存されます。

改良版を公開する場合は、このリポジトリをフォーク（Fork）してください。
不具合の報告や改良の提案は、Issues または Pull request でお寄せください。
